    02✳

    COMPONENT NOTES

    01

    Local by design.

    The FastAPI dashboard and workflow run locally. Provider calls only happen when a configured Gemini or DeepSeek integration is used; otherwise cover letters can use the built-in template.

    ORCHESTRATION · PYTHON
    LOCAL WORKFLOWOPTIONAL PROVIDER

    No public application API is represented here. Wellfound discovery and browser interaction use the signed-in Firefox session configured on the local machine.
